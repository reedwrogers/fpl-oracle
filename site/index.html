2026-03-09 Improving the model with more features

We need to add some more features in order to get better model performance. Our best predictor as of now has a -0.2 correlation with the target, and that is the xG for the team the player is going against. If we want to have a usable model, we need more predictive power from our attributes. As of now, all types of models are converging around an R-squared of 0, and in most cases they are even worse. A negative R-squared implies that the model does worse than a model that simply would predict the average of the attribute.

The priority now is to add the following: points_last_3 (average form), xG_last_3, minutes_last_3, is_penalty_taker, ownership_percent, and the three FPL ICT index statistics.

About the Model

This project scrapes Understat and the Premier League Fantasy site to build a comprehensive dataset for predicting player points. The model evolves as more data becomes available, and I continually optimize it for prediction.

A player's Fantasy Premier League points in a given week are modeled as a function of:

  • Player history: past FPL performance and position
  • Player effectiveness: expected and per-90 statistics
  • Team strength: chances created and conceded per 90
  • Opponent strength: league position and expected stats
  • Match context: gameweek and home/away status

A script runs periodically, before any games that day have begun. If the gameweek is new, then last week's predictions are appended to last week's data, and this week's data is grabbed.
